# Changelog

Author: Salman | Description: Release history for TribePay Gateway for WooCommerce.

## 1.2.0 - 2026-11-03

- Public release under Salman attribution with versioned plugin metadata.
- Added reusable merchant setup, licensing, contribution and security guidance.
- Added author and component descriptions to every code file.
- Removed client-specific presentation from the release documentation.
- Preserved payment and return behavior from 1.1.1.

## 1.1.1

- Corrected malformed return URL handling while preserving full order key validation.
- Protected newly generated return URLs with a final disposable query parameter.
- Retained server verification and paid Processing order redirects.

## 1.1.0

- Added live-only configuration, explicit configuration messages, optional webhook setup and store currency defaults.

## 1.0.0

- Initial hosted checkout implementation.
