# Contributing

Author: Salman | Version: 1.2.0
Description: Contribution guidelines for the independent TribePay WooCommerce project.

Explain the problem, expected behavior and reproduction steps. Never include credentials, order keys, personal customer data or card details in issues or pull requests. Preserve server verification, signature checks, redirect restrictions and duplicate-payment handling. Include appropriate regression checks for payment logic changes. Run the checks documented in README.md and record their scope. Do not claim live gateway verification from mocked tests. Preserve Salman attribution and GPL notices when redistributing.
